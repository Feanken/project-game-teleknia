# Teleknia pixel assets

Generated with the built-in imagegen tool. Each PNG is exactly 64 x 64 pixels.
Atlas cells were extracted row-first, then resampled using nearest-neighbor interpolation.
No runtime network requests or external image paths are required.

## Final generation prompt

Create one production game sprite atlas image, exactly square, a 4 by 4 grid of sixteen equal square cells, no gaps no borders no labels no text. Each cell is a coherent 64x64 pixel art sprite rendered with hard square pixel edges, limited palette midnight navy, desaturated teal, pale parchment and ember orange. Flat solid background #101820 throughout. Center each sprite with generous 6 pixel empty padding; no content crosses cells. Row 1: hooded dark haired young fighter portrait wearing teal scarf; rusty iron sword diagonal; glass red healing potion cork bottle; rolled parchment old map. Row 2: glowing cracked ash wolf fang; burning ruined village landscape vignette; ruined northern stone gate landscape; mysterious forest shrine with ember glow. Row 3: crimson heart health icon; blue mana crystal; gold coin stack; golden experience star. Row 4: mysterious hooded game master portrait; leather backpack; open quest journal; campfire. Rich handcrafted retro RPG pixel art shading and deliberate pixel clusters. No smooth edges no gradients no typography. All sixteen cells must be aligned in exact uniform 4x4 grid, each independent, fully visible.
